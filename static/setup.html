Set up your badges

Takes under a minute. No account, no login — the badge URLs you get back are the only thing that identifies your project.

Create a Personal Access Token in Crowdin with Granular Access, scoped to this one project only. Create a token on Crowdin →

Under Scopes, enable exactly these three and leave everything else unchecked:

Scope Access level
Projects Read only
Translation status Read only
Reports Read and Write

Why does Reports need Write access? Generating the contributor report is technically a write-style API call in Crowdin's permission model, even though it only reads translation activity — it doesn't create or change anything in your project. We don't use the Members scope at all: it lists who has project access, not how much each person has translated, which is what the contributor grid is ranked by.

The numeric project ID, not the URL slug — find it in your project under Tools → API.
